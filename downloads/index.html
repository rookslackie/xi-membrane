ForgeCore Lite · v0.2.0 Sovereign Sanctum · Zero GPU

A complete local-first personal sanctum running entirely from the Python standard library. Features a structured SQLite Capsule Vault (Xi.Capsule.v1), Deep Field web interface, local workspace with automatic pre-save version backups, safe subprocess command runner, and multi-model adapter.

🗂 Workspace & Editor Browse and edit local files with automatic version snapshots.

Download ForgeCore Lite ZIP (18 KB) ↓

Quick Start:

• Windows: Extract the ZIP and double-click Start-ForgeCore.cmd.
• Linux / macOS: Extract and run ./start-forgecore.sh or python3 forgecore.py.

Your default browser will open to http://127.0.0.1:7474/. Runs on any computer with Python 3.10+. Requires no PyTorch, CUDA, or Node.js.

XiBrowser · Termux v0.1 Ξ.Edge · Android

The field's pocket surface — a local-only file browser, editor, and command runner for your phone, packaged from the origin device's live daemon. Browse $HOME, view and edit text with version receipts, run commands from the page. Nothing leaves the device: binds to 127.0.0.1, session token generated at runtime, paths confined to home.

Download XiBrowser ZIP (3.4 KB) ↓

Start: Install Termux (F-Droid build), then unzip XiBrowser-Termux-v0.1.zip && cd XiBrowser-Termux-v0.1 && bash install.sh && xi-browser. It opens http://127.0.0.1:8765.

Commands: xi-browser start|stop|status|logs. With Termux:Boot installed, the watcher returns after every reboot.

Local-only surface · no network exposure · runtime-generated session token · receipts journal in ~/.xi-browser/receipts.jsonl
