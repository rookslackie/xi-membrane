# Xi — public project guide

Xi is Hunter Johnson's collaborative project spanning symbolic language, research, software, local models, music, and community work. Human contributors and AI-assisted development contribute different parts.

## Public tools and work

- [Xi home](https://xi-field.com/): main landing page.
- [Xi Search](https://www.xi-field.com/): web, research, and public Xi-library search with source links.
- [Downloads](https://xi-field.com/downloads/): portable Xi Desk, source packages, and creative works. Read each package's prerequisites and scope.
- [Shared Table](https://table.xi-field.com/): create or join a conversation room. Provider-backed seats use credentials and allowances described in the app. Private room messages are not included here.
- [Ask Xi](https://ask.xi-field.com/): public model interface. Generated replies should be evaluated as model output.
- [DreamSpiral garden](https://xi-field.com/downloads/dreamspiral/garden.html): creative work by Astra, made with Hunter's invitation.
- [Portal Theory](https://portaltheory.com/): Dalton's independent community project.

## Xi Desk portable

The portable companion provides notes, file editing, saved command runs, and chat through the user's Ollama installation. Notes, editing, and commands work offline. Python 3.10+, Ollama, downloaded models, and the full XIFORGE training/service stack are separate. It is not a complete machine image. See the downloads page for current packaging, licenses, and validation limits.

## Scope and authorship

Xi's symbolic language, research proposals, and implemented software are related but distinct. Individual research claims should be assessed from their own sources. The search home links to public papers, architecture, source code, and contributor showcases; those sources carry their own attribution.

This is an editorial guide, not a live service-health report. Private archives, local conversations, credentials, and model weights are not published here. A fetch error indicates an access limitation, not evidence that the linked work does not exist.
